Personal Expense Tracker

Project Overview

The Personal Expense Tracker is a Python-based desktop application developed to manage and track daily expenses. It provides a simple graphical user interface where users can enter expense details, view records, delete expenses, and monitor their total spending.

Technologies Used

- Programming Language: Python
- GUI Library: Tkinter
- Data Structures: Lists and Dictionaries
- Data Management: File Handling

Main Features

- Add expenses with name, amount, category, and date.
- Display expense records in a table.
- Delete selected expense records.
- Calculate and display total expenses.
- Use a simple and user-friendly graphical interface.

Python Concepts Used

1. Lists

Lists can store multiple expense records in an organized collection.

2. Dictionaries

Dictionaries represent individual expenses using keys such as name, amount, category, and date.

3. File Handling

File handling can be used to save expense records and retrieve them when the application starts.

4. Tkinter

Tkinter is used to build the graphical user interface, including input fields, buttons, and the expense table.

Sample Output

The application displays expense records with their names, amounts, categories, and dates.

Example:

How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python PersonalExpenseTracker.py

Tkinter is included with many standard Python installations. If it is unavailable, install or enable the appropriate Tkinter package for your Python environment.
